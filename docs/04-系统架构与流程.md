## 4. 工作流
~~~mermaid
flowchart TD
  T[17:00 / 登录 / 解锁触发] --> D{今日已完成?}

  BR2 -->|失败/未知/需人工| M
  BR -->|未知/需人工| M
~~~

## 5. 单游戏状态机
~~~mermaid
stateDiagram-v2
  [*] --> NOT_STARTED
  NOT_STARTED --> RUNNING
  RUNNING --> SUCCEEDED
  RUNNING --> RETRY_WAIT: 明确失败且可安全重试
  RUNNING --> UNKNOWN: 结果不明
  RUNNING --> NEEDS_ATTENTION: 人工介入
  RUNNING --> INTERRUPTED: 锁屏/中断
  RETRY_WAIT --> RUNNING: 第二次尝试
  RUNNING --> FAILED: 第二次明确失败
  INTERRUPTED --> RUNNING: 解锁后核验并恢复
~~~

## 6. 恢复规则
启动时检查单实例锁、当天数据库状态、遗留 RUNNING、第三方进程、日志和桌面状态。已确认成功则不重启；进程仍运行则继续监控；明确失败且可安全重试才重试；UNKNOWN 不自动重跑；锁屏则等待解锁。

## 7. 时间规则
以 Windows 本机时区为准；business_date 为 YYYY-MM-DD；17:00 是触发检查时间。跨午夜的运行仍归属启动时业务日期，不自动开启第二轮。

## 8. 数据模型
- daily_runs：id、business_date（唯一）、status、started_at、finished_at。
- game_runs：id、daily_run_id、game_key、status、attempt_count、started_at、finished_at、last_error。
- attempts：id、game_run_id、attempt_no、pid、exit_code、started_at、finished_at、result_status、log_path、error_summary。

## 9. 架构约束
编排器不直接调用 subprocess；适配器不写全局工作流状态；CLI 不直接访问 SQL；外部进程统一经 ProcessRunner；状态先持久化再执行外部副作用。
