# 外部工具适配器说明（阶段 2）

本文区分公开文档已说明的能力、目标机器已提供的核查证据、项目当前实现和仍需完成的验证。任何本机验证结论都必须记录工具版本、完整命令参数、执行时间、退出码、日志/结构化结果证据；未验证内容不得升级为正式默认值。

## 1. 统一接口和边界

- `domain.adapter.GameAdapter` 定义 `game_key`、`check_available()`、`execute_daily()`、`identify_result()`。
- `BetterGIAdapter` 和 `March7thAdapter` 各自只绑定对应 `GameToolConfig`，独立初始化。
- 两个适配器共用 `infrastructure.ProcessRunner`，使用 argv 参数列表、`shell=False`，不拼接 shell 命令。
- 适配器不负责 BetterGI → March7th 的全局顺序。
- 配置中的 `arguments` 和 `version_arguments` 默认为空。只有在目标机器完成对应验证后才可填写；代码不推断 CLI 开关或任务 ID。
- 结果分类没有默认猜测规则。没有已验证的工具专属分类器时，即使进程退出码为 0，结果仍为 `UNKNOWN`。

## 2. 结果语义

| 结果 | 含义 |
|---|---|
| `NOT_CONFIGURED` | 可执行文件或任务参数尚未配置 |
| `START_FAILED` | OS 无法创建目标进程，例如路径错误或权限问题 |
| `SUCCESS` | 仅当经过验证的工具专属结果分类器确认任务成功 |
| `FAILED` | 仅当经过验证的工具专属结果分类器确认任务明确失败 |
| `UNKNOWN` | 超时、证据不足、状态不一致或尚无可靠分类规则 |

`ProcessRunner` 当前以 `subprocess.run` 同步等待并捕获输出。超时结果标记为 UNKNOWN；子进程树终止/接管、锁屏中断恢复和长时间持续监控属于后续基础设施阶段，当前不可据此宣称已解决。

## 3. BetterGI：公开资料与本机核查

官方命令行文档列出以下形式：

- `BetterGI.exe start`
- `BetterGI.exe startOneDragon`
